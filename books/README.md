# Book downloads: preparation in progress

The [language pages](downloads/) show preparation status. No finished Word or PDF books are published by this tooling yet; the two-lesson Arabic layout proof is not a complete book. Existing repository downloads remain available in the root README.

The exporter is staged for the approved 6 × 9 inch presentation, using the new extended Essential Iman Hadiths only. It must preserve complete current reader material, source qualifications, localized references and existing order. Historical or held editions and source archives are excluded. Non-Arabic summaries remain AI translated and require verification.

Before any book release, connect a producer that binds every eligible current catalogue record to normalized source-bound reader units, with verified collection and narration references. Resolve native surah names without English fallbacks. Install the pinned cover and font archives from the approved release, run the Linux LibreOffice two-pass export, and inspect every generated language and category. Japanese and Urdu combined editions require their separately specified complete current units and source revisions. A stale, missing or mismatched unit must block publication.

The production indexer is deliberately held until the public catalogue has been reconciled with current app content; the catalogue alone does not establish that older Seerah entries are current. The workflow currently runs download-table tests only. It does not build or publish books and does not update links. The 20 language pages contain preparation text until verified Word/PDF pairs are actually released. Prior releases and the existing README guidance are not replaced.

Tests use fixtures solely for validation; fixtures are not downloadable books. See the code and configuration for the normalized unit contract and safeguards.
