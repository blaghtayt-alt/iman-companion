# Heart Reminder: selected Quran passages

These are 84 protected placement identities in five languages: 418 qualified whole language placements and two held Vietnamese placements. The source package contains 558 independently reviewed verse bodies; 557 are published here, and one individually reviewed Vietnamese body is withheld as part of a held whole placement. These selections do not complete the Quran or the Heart collection.
