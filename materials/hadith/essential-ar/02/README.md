# النية والإخلاص

الباب الثاني من النص الجامع للأحاديث

تسعة مداخل في تصحيح النية وإخلاص العمل لله، وموافقة السنة، وصدق القلب وآثار ذلك في العمل والقبول والجزاء؛ تجمع الشرح والتأمل والشواهد القرآنية والنبوية في سياق متصل.

يبدأ كل مدخل بنص الرواية ومرجعها، ثم يتبعه شرح متصل يجمع معانيها وشواهدها وروابطها بالآيات والأحاديث الأخرى. وتبقى الروايات المتقاربة مداخل مستقلة حين يختلف لفظها أو وجه دلالتها.
