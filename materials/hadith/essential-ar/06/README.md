# الصبر والشكر والرضا

الباب السادس من النص الجامع للأحاديث

سبعة عشر مدخلا في الصبر والشكر والرضا، تتناول استقبال النعم والمصائب، والصبر على أذى الناس، وشكر المنعم، والرضا بالله ودينه ورسوله، والثبات على الدين؛ تجمع الشرح والتأمل والشواهد القرآنية والنبوية في سياق متصل.

يبدأ كل مدخل بنص الرواية ومرجعها، ثم يتبعه شرح متصل يجمع معانيها وشواهدها وروابطها بالآيات والأحاديث الأخرى. وتبقى الروايات المتقاربة مداخل مستقلة حين يختلف لفظها أو وجه دلالتها.

الآيات القرآنية   •   الأحاديث والنقول المقتبسة   •   المراجع
