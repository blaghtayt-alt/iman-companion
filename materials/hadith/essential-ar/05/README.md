# التوبة ومحاسبة النفس

الباب الخامس من النص الجامع للأحاديث

خمسة مداخل في التوبة والاستغفار ومحاسبة النفس، تبين أثر الذنوب في القلب، وسبيل مجاهدة الهوى وإصلاح التقصير بالحسنات، وسعة فضل الله في قبول من رجع إليه؛ تجمع الشرح والتأمل والشواهد القرآنية والنبوية في سياق متصل.

يبدأ كل مدخل بنص الرواية ومرجعها، ثم يتبعه شرح متصل يجمع معانيها وشواهدها وروابطها بالآيات والأحاديث الأخرى. وتبقى الروايات المتقاربة مداخل مستقلة حين يختلف لفظها أو وجه دلالتها.

الآيات القرآنية   •   الأحاديث والنقول المقتبسة   •   المراجع
