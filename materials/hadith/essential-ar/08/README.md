# سلامة الصدر وحسن الخلق

الباب الثامن من النص الجامع للأحاديث

ثلاثون مدخلا في سلامة الصدر وحسن الخلق، تتناول الرحمة والمحبة والنصح والصدق والحياء والعفو والإحسان، وأثرها في صحبة الناس وتربية الأولاد وحمل المسؤولية؛ تجمع الشرح والتأمل والشواهد القرآنية والنبوية في سياق متصل.

يبدأ كل مدخل بنص الرواية ومرجعها، ثم يتبعه شرح متصل يجمع معانيها وشواهدها وروابطها بالآيات والأحاديث الأخرى. وتبقى الروايات المتقاربة مداخل مستقلة حين يختلف لفظها أو وجه دلالتها.

الآيات القرآنية   •   الأحاديث والنقول المقتبسة   •   المراجع
