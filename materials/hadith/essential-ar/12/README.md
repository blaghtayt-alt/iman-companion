# الدنيا والآخرة

الباب الثاني عشر من النص الجامع للأحاديث

خمسة عشر مدخلًا في الدنيا والآخرة، تجمع غنى القلب والقناعة، والحذر من فتنة الدنيا وطول الأمل، والاستعداد للقاء الله، ومشاهد الحشر والميزان والشفاعة والقصاص.

يبدأ كل مدخل بنص الرواية ومرجعها، ثم يتبعه شرح متصل يجمع معانيها وشواهدها وروابطها بالآيات والأحاديث الأخرى. وتبقى الروايات المتقاربة مداخل مستقلة حين يختلف لفظها أو وجه دلالتها.
