# صلاح القلب وأمراضه وعلاجها

الباب السابع من النص الجامع للأحاديث

تسعة وثلاثون مدخلا في صلاح القلب وأمراضه وعلاجها، تتناول أثر القلب في الإيمان والعمل، وتجديده وتقلبه، وعلاج الوساوس والكبر والعجب والحسد والغضب والشهوات؛ تجمع الشرح والتأمل والشواهد القرآنية والنبوية في سياق متصل.

يبدأ كل مدخل بنص الرواية ومرجعها، ثم يتبعه شرح متصل يجمع معانيها وشواهدها وروابطها بالآيات والأحاديث الأخرى. وتبقى الروايات المتقاربة مداخل مستقلة حين يختلف لفظها أو وجه دلالتها.
