# حقوق الناس والمعاملات والأحكام

الباب الحادي عشر من النص الجامع للأحاديث

ثلاثة وثلاثون مدخلًا في حقوق الناس والمعاملات وأحكام الحياة، تجمع حفظ الحقوق ودفع الظلم، وآداب البيع والشراكة والوفاء بالعهود، وأحكام الميراث والأسرة والقضاء، وصلة الرحم وبر الوالدين.

يبدأ كل مدخل بنص الرواية ومرجعها، ثم يتبعه شرح متصل يجمع معانيها وشواهدها وروابطها بالآيات والأحاديث الأخرى. وتبقى الروايات المتقاربة مداخل مستقلة حين يختلف لفظها أو وجه دلالتها.
