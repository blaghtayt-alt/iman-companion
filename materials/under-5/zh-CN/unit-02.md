# 第二单元：我与真主的关系

## 第十一课：我向真主祈求

我们学过，真主听得见我们的话...

也知道我们需要什么...

来想一想...

口渴时，我们需要什么？...

...

水...

水是真主给我们的...

我们吃的食物也是...

我们可以向真主祈求自己需要的东西...

我们一起试一试吧...

真主啊...

求你给我们水喝...

...

真棒！...

我们向真主祈求...

这就叫作祈祷...

向真主祈祷...

就是向他祈求，向他请求...

我们也请家人给我们水喝...

是真主让我们有家人的帮助...

现在，选一样我们需要的东西吧...

是喝的水？...

还是吃的食物？...

...

你可以向真主祈求你选的东西...

我们先说：真主啊...

再向他祈求自己需要的东西...

...

真棒！...

真主听得见我们的祈祷...

## 第十二课：我祈求真主保护我

想想和家人一起出门的时候吧...

过马路的时候...

我们牵着家里一位大人的手...

你记得是谁牵着你的手吗？...

你可以说说你想起了谁...

...

真棒！...

家人帮助我们...

我们也祈求真主保护我们...

就是保护我们不受伤害...

我们一起说吧...

真主啊，求你保护我...

...

真棒！...

我们还可以说...

أَعُوذُ بِاللهِ...

意思是，我祈求真主保护我...

我们一起说吧...

أَعُوذُ بِاللهِ...

...

真棒！...

现在，想想我们的家人吧...

我们爱他们...

也希望真主保护他们...

我们为自己和家人祈祷吧...

真主啊，求你保护我，也保护我的家人...

...

真棒！...

我们待在家人身边...

也向真主祈求保护...

## 第十三课：我感谢真主

想一样我们喜欢吃的食物吧...

你想起了什么食物？...

你可以说出它的名字...

...

真棒！...

这食物是真主给我们的供养...

真主给了我们水...

使植物为我们生长...

也给了我们身体...

想起真主给我们的这些东西...

我们就感谢他...

感谢他的一种方式，就是说...

الْحَمْدُ لِلهِ...

我们说的时候，想着真主给我们的恩典...

我们一起说吧...

الْحَمْدُ لِلهِ...

...

真棒！...

现在，再选一样恩典吧...

是用来看东西的眼睛？...

还是用来听声音的耳朵？...

...

你可以说说你选了什么...

然后，我们一起说...

الْحَمْدُ لِلهِ...

...

真棒！...

家里有人为我们准备食物时...

我们感谢他的帮助...

也赞美给我们食物的真主...

这样，我们每天都记着真主...

## 第十四课：我爱真主

想一个我们喜欢听的声音吧...

妈妈的声音？...

或者家里其他人的声音？...

你想起了什么声音？...

...

真棒！...

真主给了我们耳朵，让我们能听见...

给了我们眼睛，让我们能看见...

他创造我们，也供养我们...

他还听得见我们的祈祷...

每当想起这些恩典...

我们就想起把它们给我们的真主...

我们爱真主...

我们一起说吧...

我爱真主...

...

真棒！...

因为我们爱真主...

所以也愿意做他喜爱的事...

比如帮助家人...

想一件能帮上忙的小事吧...

我们可以做什么？...

...

我们可以把自己的玩具放回原处...

让家人更容易收拾房子...

你也可以说说别的帮忙方法...

...

真棒！...

我们爱真主...

也愿意做他喜爱的事...

## 第十五课：我们只崇拜真主

想想我们学过的内容吧...

需要一样东西时...

我们向真主祈祷...

想起他给我们的东西时...

我们说：الْحَمْدُ لِلهِ...

我们从这两样里选一样吧...

选一句向真主祈求的话...

或者选一样恩典，为此赞美他...

然后说说我们选的是什么...

...

真棒！...

我们向真主祈求...

赞美他，感谢他...

我们为真主做这些事...

因为我们爱他，也愿意服从他...

就是做他命令我们做的事...

不做他命令我们不要做的事...

这些都属于崇拜...

我们只崇拜真主...

他创造了我们，也供养我们...

没有谁像他...

我们一起把一句话说完整吧...

我们只崇拜...

...

真主...

现在，我们说完整句话...

我们只崇拜真主...

...

真棒！...

礼拜也是我们崇拜真主的一种方式...

我们会一起来认识礼拜...

## 第十六课：穆斯林为真主礼拜

你见过家人礼拜吗？...

你可以告诉我，你想起了什么...

...

真棒！...

穆斯林礼拜的时候...

就是在崇拜真主...

礼拜时，他们记念真主，向他祈祷...

礼拜有一些话语和动作，需要我们学习...

站立就是其中一个动作...

我们试着安静地站一站吧...

只站一小会儿...

...

真棒！...

站立是礼拜的一部分...

其他动作和话语，我们跟家人一起学...

一步...

一步...

我们想一想...

穆斯林为谁礼拜呢？...

...

为真主...

我们为创造了我们的真主礼拜...

我们爱他，也崇拜他...

我们可以请一位家人教教我们...

来练习说出这个请求吧...

我想跟你一起学礼拜...

...

真棒！...

## 第十七课：做错了事，我归向真主

有时候，我们会做错事...

比如拿了朋友的玩具...

却没有得到他的允许...

后来，我们知道自己做错了...

希望自己没有做过那件事...

那现在，我们可以怎么做呢？...

我们想一想...

...

先停止做错事...

把玩具还给朋友...

因为那是他的玩具...

我们对他说...

对不起...

我们来练习说吧...

对不起...

...

真棒！...

我们愿意不再拿别人的东西...

除非他们允许...

我们也祈求真主原谅我们...

我们说...

真主啊，求你饶恕我...

我们一起说吧...

真主啊，求你饶恕我...

...

真棒！...

我们不再做错事...

并且改正自己的错误...

祈求真主饶恕我们...

这样，我们归向真主...

这就叫作悔过...

真主接受归向他的人的悔过...

现在，再想想那件玩具吧...

如果还想玩朋友的玩具...

拿之前，我们要做什么？...

...

我们问他...

你可以让我玩一玩吗？...

我们试着说说这句话吧...

...

真棒！...

他允许了，我们才玩...

我们从错误中学习...

归向真主...
