# 第5単元：アッラーに仕える行いを学びましょう

## 第32課：ザカート

家族が食べものを買うところを見たことがありますか...

...

必要なものを買うときは、お金をはらいます...

家族といっしょに買ったものを思い出しましょう...

何を思い出しましたか...

...

よくできました...

十分なお金を持っていない人もいます...

食べものや...

必要な服を買うお金です...

こういう人たちは、まずしい人の中に入ります...

アッラーは、ムスリムの中のある人たちに、持っているものの一部をわたすよう命じました...

どれだけわたすかを決め...

だれにわたすかも決めました...

このようにわたすことを「ザカート」と言います...

ムスリムは、自分がいつザカートを出す必要があるか学びます...

そして、アッラーが命じたとおりに出します...

ザカートを受け取る人の中には...

さっき話した、まずしい人たちもいます...

食べものを必要としている家族を考えましょう...

でも、買うお金が十分にありません...

ザカートのお金を受け取ったら...

それで何を買うことができるでしょう...

...

食べものを買うことができます...

買える食べものを、ひとつ言いましょう...

...

よくできました...

こうして、受け取る権利のある人にザカートが届きます...

生きるためのめぐみをくださったのはアッラーだと思い出します...

だから、いただいたものについても、アッラーに従います...

いっしょに言いましょう...

アルハムドゥ・リッラー...

...

よくできました...

## 第33課：ラマダーンと断食

ラマダーンということばを聞いたことがありますか...

...

ラマダーンは、毎年めぐってくる月です...

アッラーは、ムスリムにラマダーンの断食を命じました...

断食をする人は、何をするのでしょう...

食べることと飲むことをやめます...

夜明けから...

つまり、お日さまが出る前の、朝の始まりからです...

お日さまがしずむまでです...

アッラーに仕えるために、こうします...

いっしょに考えましょう...

お日さまがしずんだら...

断食をしている人は、何ができますか...

...

食べたり飲んだりできます...

断食を終えて食事をする時間になったからです...

断食をしなくてもよいと、アッラーがゆるした人もいます...

病気の人や旅をしている人などです...

あなたは、まだ小さいので...

今は、まだ断食をしなくていいのです...

昼間も食べたり飲んだりしてかまいません...

家族といっしょに、断食のことを学ぶことができます...

断食を終えたあとの食事の用意を、お手伝いすることもできます...

小さなお手伝いを選びましょう...

テーブルにナプキンを置きますか...

それとも、家族といっしょに場所をととのえますか...

何を選びましたか...

...

よくできました...

どんなお手伝いをしたいか、家族に伝えることができます...

やってみましょう...

断食を終えたあとの食事の用意を、お手伝いしたいです...

...

よくできました...

ラマダーンには、クルアーンを聞きます...

アッラーにドゥアーをします...

そして、断食はアッラーに仕える行いだと思い出します...

## 第34課：カアバとハッジ

今日は、マッカという場所について学びましょう...

マッカには、カアバという建物があります...

カアバの絵や写真を見たことがありますか...

...

家族に、絵や写真を見せてくださいとお願いできます...

お願いしてみましょう...

カアバの絵や写真を見たいです...

...

よくできました...

絵や写真が目の前にあれば...

家族に手伝ってもらって、カアバがどれかたしかめられます...

そして、カアバを指してみましょう...

...

よくできました...

いろいろな場所から、ムスリムがマッカに行きます...

アッラーのために、ハッジという巡礼をするためです...

ハッジには、決まった時期があります...

ムスリムがやり方を学ぶ行いもあります...

ハッジの行いのひとつが、カアバのタワーフです...

つまり、アッラーに仕えるために、カアバのまわりを回ることです...

ムスリムはアッラーにドゥアーをし...

アッラーを思います...

思い出しましょう...

ムスリムは、だれのためにハッジをしますか...

...

アッラーのためです...

わたしたちは、アッラーだけに仕えます...

マッカでも、どこにいてもです...

ここにいるわたしたちも、その人たちのためにアッラーにドゥアーができます...

その人たちのために、アッラーに何をお願いしたいですか...

...

守ってくださいとお願いすることができます...

いっしょに言いましょう...

アッラーよ、その人たちをお守りください...

...

よくできました...

その人たちは、マッカでアッラーにドゥアーをします...

わたしたちは、ここでアッラーにドゥアーをします...

アッラーは、みんなのドゥアーを聞いています...
