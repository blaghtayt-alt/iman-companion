# 第1単元：アッラーを知りましょう

## 第1課：アッラー

さあ、いっしょに始めましょう...

アッラー...

この名前を聞いたことがありますか...

ゆっくり思い出しましょう...

おぼえていることを、わたしに話してもいいですよ...

...

この名前をいっしょに言いましょう...

アッラー...

こんどは、あなたがこの名前を言うばんです...

...

よくできました...

この名前から始めます...

これから毎回、アッラーについて新しいことを知っていきましょう...

## 第2課：アッラーはただおひとりだと信じます

この名前を知りましたね...

アッラー...

今日は、アッラーはただおひとりだと学びます...

ふたりでも、三人でもありません...

指を一本出してみましょう...

一本だけです...

「ひとつ」ということばをおぼえるためです...

...

よくできました...

こんどは、いっしょに文を完成させましょう...

わたしが始めのところを言います...

あなたは、さいごのことばを言ってください...

わたしたちが信じるアッラーは...

...

ただおひとりです...

信じるとは、ほんとうだと思うことです...

こんどは、文をぜんぶいっしょに言いましょう...

わたしたちが信じるアッラーは、ただおひとりです...

...

よくできました...

## 第3課：アッラーがわたしをつくりました

アッラーがわたしたちをつくりました...

そして、わたしたちに体をくださいました...

今日は、よく使うものを見てみましょう...

わたしたちの両手です...

いっしょに両手を見ましょう...

そっと手をひらきます...

それから、そっとにぎります...

もう一度ひらきます...

...

よくできました...

こんどは、指を動かしましょう...

一本の指を動かしてみます...

それから、ほかの指も動かしてみます...

...

よくできました...

両手で何ができますか...

ひとつ考えましょう...

...

わたしたちは手でコップを持ちます...

おもちゃも持ちます...

だれがわたしたちの両手をつくり...

動かせるようにしてくれたのでしょう...

...

アッラーです...

見るための目もあります...

近くにあるものを見てみましょう...

何が見えますか...

見えるものを言ってもいいですよ...

...

よくできました...

アッラーが、ものを見る目をつくりました...

音を聞く耳もつくりました...

話すときに使う舌とくちびるもです...

わたしたちは、自分で自分をつくったのではありません...

生まれる前は...

お母さんのおなかの中にいました...

わたしたちの体をつくったのはアッラーです...

それから、生まれてきました...

そして、少しずつ大きくなりました...

体は、アッラーからいただくめぐみのひとつです...

めぐみとは、アッラーがくださるよいものです...

たとえば、手や目や耳です...

こんどは、体の一部を選びましょう...

手、目、耳のどれかです...

そして考えましょう...

それを使って何をしますか...

目を選んだら...

目でものを見ることを思い出します...

そして言いましょう...

アッラーがわたしの目をつくりました...

あなたは何を選びましたか...

選んだものについて話しましょう...

...

よくできました...

いっしょに言いましょう...

アッラーがわたしをつくりました...

...

よくできました...

## 第4課：アッラーがわたしの見るものをつくりました

手と目について話しましたね...

こんどは、家の外で見たものを思い出しましょう...

木を思い出せますか...

鳥はどうでしょう...

わたしたちの上にある空はどうでしょう...

ひとつ選びましょう...

そして名前を言いましょう...

ゆっくり考えましょう...

...

よくできました...

木をつくったのはアッラーです...

鳥をつくったのもアッラーです...

空もアッラーがつくりました...

鳥が二枚のつばさをひろげるところを思いうかべましょう...

鳥には、なぜつばさがいるのでしょう...

少し考えましょう...

...

鳥はつばさで飛びます...

鳥をつくったのはアッラーです...

二枚のつばさをくださいました...

昼と夜を思い出しましょう...

お日さまは、いつわたしたちを照らしますか...

夜でしょうか、昼でしょうか...

...

お日さまは昼にわたしたちを照らします...

夜になると、まわりは暗くなります...

空に星が見えることもあります...

アッラーが、お日さまと星をつくりました...

わたしたちのために夜と昼をつくりました...

わたしたちが歩く地面もつくりました...

こんどは、あなたのばんです...

今話した、アッラーがつくったものをひとつ言ってみましょう...

...

よくできました...

## 第5課：アッラーに似ているものはありません

両手をならべましょう...

そして見てみましょう...

...

よくできました...

両手に似ているところはありますか...

少し考えましょう...

...

どちらの手にも指があります...

どちらの手にも手のひらがあります...

だから、こう言います...

こちらの手は、もう一方の手に似ています...

木が、ほかの木に似ていることもあります...

鳥が、ほかの鳥に似ていることもあります...

似ているものをふたつ思い出しましょう...

思い出したものを言ってもいいですよ...

...

よくできました...

これらは、アッラーがつくったものです...

「つくられたもの」と呼びます...

つまり、アッラーがつくったものです...

でも、アッラーは...

ご自分がつくったどんなものにも似ていません...

アッラーはわたしたちに似ていません...

アッラーは、つくり主です...

つまり、わたしたちをつくり...

まわりのものもつくったお方です...

もう一度、両手を見ましょう...

だれがこの両手をつくりましたか...

...

アッラーです...

わたしたちの両手は、つくられたものです...

わたしたちをつくったアッラーは...

ご自分がつくったどんなものにも似ていません...

## 第6課：わたしたちにはアッラーが必要です

のどがかわいたときを思い出しましょう...

のどがかわくと、何が必要ですか...

飲むための水ですか...

それとも、遊ぶためのおもちゃですか...

考えてみましょう...

...

わたしたちの体には水が必要です...

手を動かしてみましょう...

コップを持って、そこから飲むつもりで動かします...

...

よくできました...

おなかがすいたときは...

何が必要ですか...

...

食べものです...

つかれたときは...

休んだり、ねむったりする必要があります...

大人のことを考えましょう...

大人も飲んだり食べたりしますか...

大人が水を飲むところを見たことがありますか...

...

わたしたちは、小さいときも、これらのものが必要です...

大きくなっても、やはり必要です...

でも、アッラーは...

食べものを必要としません...

水も...

ねむることも必要としません...

アッラーは、何も必要としません...

わたしたちは、いつもアッラーを必要としています...

わたしたちをつくったのはアッラーです...

わたしたちに必要な水や植物もつくりました...

体に必要なものを、ひとつ言いましょう...

...

よくできました...

そして、おぼえておきましょう...

わたしたちにはアッラーが必要です...

## 第7課：アッラーには力があります

ひろい空を思い出しましょう...

小さな葉っぱも思い出しましょう...

どちらが大きいでしょう...

空ですか、葉っぱですか...

少し考えましょう...

...

空はとてもひろいですね...

両手を少しはなしてみてもいいですよ...

そして言いましょう...

空はひろいです...

...

よくできました...

こんどは両手を近づけます...

そして言いましょう...

葉っぱは小さいです...

...

よくできました...

アッラーがひろい空をつくりました...

植物と、その小さな葉っぱもつくりました...

大きなものをつくることは、アッラーにはむずかしくありません...

小さなものをつくることも、むずかしくありません...

アッラーには力があります...

つまり、ご自分が望むことをする力があります...

こんどは、あなたのばんです...

アッラーがつくった動物を思い出せますか...

植物も思い出せますか...

思い出したものの名前を言いましょう...

...

よくできました...

これらをつくるアッラーの力を思い出しましょう...

## 第8課：アッラーは生きるために必要なものをくださいます

好きなくだものを考えましょう...

どのくだものを選びますか...

くだものの名前を言ってもいいですよ...

...

よくできました...

食べものの中には、地面から育つものがあります...

小さな植物を思いうかべましょう...

大きくなるためには、何が必要でしょう...

少し考えましょう...

...

水が必要です...

指を動かしましょう...

少しずつ下へ...

水のしずくが落ちてくるように動かします...

...

よくできました...

アッラーが雨を降らせます...

すると、水が地面に届きます...

アッラーは、水で植物を育てます...

わたしたちの食べものが育ちます...

くだもののなる木も育ちます...

人も働きます...

植物を植え...

水をやり...

食べものを集めます...

それが、わたしたちの家に届きます...

そして、家族が用意してくれます...

だれが水と植物をつくり...

人が働けるようにしてくれたのでしょう...

...

アッラーです...

これは、アッラーからいただく、生きるためのめぐみです...

アッラーは、飲むための水をくださいます...

食べるための食べものもくださいます...

前に話した鳥も...

食べものが必要でしょうか...

...

鳥は自分の食べものを探します...

アッラーは、わたしたちと同じように、鳥にも生きるためのめぐみをくださいます...

さっき選んだくだものを思い出しましょう...

名前を言ってもいいですよ...

それから言いましょう...

これは、アッラーからいただく、生きるためのめぐみです...

...

よくできました...

## 第9課：アッラーは知っています

好きなくだものについて話しましたね...

もう一度、くだものを選びましょう...

でも、こんどは...

そのことばを心の中だけで考えます...

声には出しません...

ゆっくり考えましょう...

...

よくできました...

わたしたちは、ことばにしなくても...

何かを考えることができます...

アッラーは、わたしたちが何を考えているか知っています...

まだことばにする前からです...

こんどは、選んだことばを声に出してもいいですよ...

...

よくできました...

いっしょに考えましょう...

声に出さず、心の中で考えていることばも...

アッラーは知っているでしょうか...

...

アッラーは、わたしたちが考えていることを知っています...

話すことも知っています...

わたしたちのことを、すべて知っています...

どこにいるかも...

何が起こるかも知っています...

うれしい気持ちも、かなしい気持ちも知っています...

うれしくなることを思い出しましょう...

それについて話してもいいですよ...

...

よくできました...

アッラーは、わたしたちの気持ちも知っています...

木から葉っぱが落ちたときも...

わたしたちが見ていなくても...

アッラーは、その葉っぱのことを知っています...

わたしたちに見えるものも、見えないものも...

アッラーはすべて知っています...

## 第10課：アッラーは聞いています

心の中で考えることばについて話しましたね...

アッラーは、わたしたちが考えることを知っていると学びました...

こんどは、短い文を言いましょう...

わたしは、ここにいます...

あなたのばんです...

いっしょに言いましょう...

わたしは、ここにいます...

...

よくできました...

アッラーは、わたしたちのことばを聞いています...

ふつうの声で話すときも...

小さな声で話すときもです...

聞いてもらうために、大声を出す必要はありません...

考えてみましょう...

何かを考えて...

声に出さなかったときも...

アッラーは知っているでしょうか...

...

はい...

アッラーは、わたしたちが考えることを知っています...

話さなくてもです...

アッラーは、わたしたちのことばを聞き...

考えていることも知っています...

アッラーは、すべてを聞くお方です...

すべての音を聞いています...

アッラーの聞き方は、わたしたちの聞き方に似ていません...

わたしたちに何が必要か知っています...

そして、わたしたちのことばを聞いています...

何かが必要なとき、アッラーに何と言えばよいでしょう...

次は、そのことをいっしょに学びましょう...
