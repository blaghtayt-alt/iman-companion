# イフラース章の出典について

アフマド・アブドゥルムンイムによる、現在のアラビア語原文の全四部分を対象としています。クルアーンの日本語引用は、東京ジャーミイ出版会『クルアーン 日本語読解』（二〇二二年二月一日発行）の本文と訳注を原本の字形に照らして確認し、そのまま保持しています。代名詞の説明に限り、原文のアラビア語を文法上の例として示しています。日本語訳にない代名詞を、出版社の言葉として補ってはいません。

その他の引用には、『イスラームの基本知識』、サイード佐藤訳の『特別なズィクル』『就寝の際の礼儀作法』『病人のお見舞いに関する礼儀作法』、サイード佐藤・ファーティマ佐藤訳『ムスリムの砦』、ハディース百科事典、大塚マスジドの礼拝説教要約を用いています。直接アラビア語から意味を伝えた箇所は、既刊の日本語訳と区別して記録しています。預言者の言葉、教友の言葉、歴史的な記述、語の用例、出所を特定しない言い回しを混同していません。

読解に必要な出版社の訳注十一件と、報奨および洞窟での助けについての説明二件を、読める状態で保持します。三回の読誦についての報奨への期待は、クルアーン全体を読み、学び、従うことや、礼拝でのファーティハ章の代わりを意味しません。伝承経路や評価の相違、版ごとの参照番号、原文の全体と出典の条件は、別の資料記録に保存しています。

今回の対照確認では、読解文・引用・訳注の言葉を変更していません。『ムスリムの砦』の同じ祈りが二度載る頁では、朝の百回の箇所を指すよう資料内の位置情報を正し、イブラーヒームの引用に付いた出版社の参照番号と、別に確認した並行伝承を区別しました。

通常の読書画面には、短い書名と翻訳の出典、意味に必要な訳注・説明、Its The Quranのチャンネル案内だけを示します。詳しい版・参照先・検討記録や頁の画像を、通常の画面に追加するものではありません。東京ジャーミイ版の本文と訳注に関する既存の利用許可は、利用者による確認に基づいています。他の本や資料すべてについて同じ許可があると推測してはいません。

本文の作成者とは異なるモデルが、原文・日本語・出典を全体にわたり対照し、日本語だけでも通読しました。これは人間、母語話者、宗教学者による認証や、アプリの動作確認ではありません。資料提供元の通知条項など、広い再配布許諾に関する未解決の点は外部記録に明記し、通知済み・免除済みとはしていません。誰にも連絡を送っていません。
